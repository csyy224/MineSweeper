# MineSweeper · 控制台扫雷

一个基于 C++23 实现的 Windows 控制台扫雷游戏，采用面向对象设计，模块清晰，支持三种难度、翻格与插旗操作，手写棋盘生成、邻雷统计与字符渲染逻辑。

---

## 1. 项目简介

本项目是一个纯文本界面的扫雷游戏，运行于 Windows 控制台。程序随机布雷，玩家通过输入命令翻格或插旗，翻出所有非雷格即获胜，踩雷即失败。

核心特点：

- 三种预设难度（初级 / 中级 / 高级）
- 邻雷数量自动统计并渲染
- 支持“插旗 / 取消插旗”
- 游戏结束自动揭示所有地雷
- 模块化设计：`Cell` / `Board` / `Game` 职责分离

---

## 2. 功能特性

| 功能 | 说明 |
| --- | --- |
| 难度选择 | 初级 10×10 / 20 雷，中级 15×15 / 60 雷，高级 20×20 / 150 雷 |
| 随机布雷 | 使用 `std::mt19937` 随机数引擎，避免重复布雷 |
| 邻雷统计 | 每个格子记录周围 8 格的雷数 |
| 翻格 | `r <row> <col>` 翻开指定格子 |
| 插旗 | `f <row> <col>` 插旗 / 取消插旗 |
| 胜负判定 | 翻开所有安全格获胜；踩雷立即失败 |
| 自动揭示 | 游戏结束后以 `X` 显示所有未翻开的地雷 |
| 控制台美化 | 自定义标题、配色与清屏，提升可读性 |
